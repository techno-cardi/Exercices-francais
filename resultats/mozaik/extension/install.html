Installer l’extension Chrome Mozaïk

Cette extension permet au bouton « Envoyer dans Mozaïk » de la console enseignant de communiquer directement avec l’onglet Mozaïk déjà ouvert. Le jeton Mozaïk reste dans Chrome.

Télécharger le dépôt ZIP

1. Décompresse le fichier ZIP téléchargé.
2. Dans Chrome, ouvre chrome://extensions.
3. Active Mode développeur en haut à droite.
4. Clique Charger l’extension non empaquetée.
5. Sélectionne le dossier Exercices-francais-main/resultats/mozaik/extension.
6. Recharge la console de synchronisation. Elle doit afficher Extension Chrome détectée.
Pour une mise à jour future : retélécharge le dépôt, remplace le dossier local, puis clique sur le bouton de rechargement de l’extension dans chrome://extensions.
