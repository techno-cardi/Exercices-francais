Installer « Synchroniser Mozaïk »

Ce favori s’exécute uniquement dans Mozaïk. Il utilise la session Microsoft déjà ouverte dans ton navigateur et ne transmet jamais ton jeton Mozaïk à GitHub ou Supabase.

1. Fais glisser ce bouton dans ta barre de favoris Chrome, ou utilise le bouton Copier.
Synchroniser Mozaïk
Chargement du favori actuel…
2. Dans la console de synchronisation, prépare un travail.
3. Ouvre Mozaïk et clique sur le favori. Aucun code temporaire n’est demandé.

Le favori récupère uniquement la synchronisation la plus récente préparée dans ta propre session enseignant. La petite fenêtre se ferme automatiquement après une réussite.
