Installer « Synchroniser Mozaïk »

Ce favori s’exécute uniquement dans Mozaïk. Il utilise le jeton déjà présent dans ta session ouverte, sans l’envoyer à Supabase ni à GitHub.

1. Fais glisser ce bouton dans ta barre de favoris Chrome :
Synchroniser Mozaïk
2. Fais la même installation une fois sur ton autre ordinateur, sauf si tes favoris Chrome sont déjà synchronisés.
3. Quand un code est préparé dans la console, ouvre Mozaïk, clique sur le favori et entre le code temporaire.

Le connecteur demande toujours une confirmation avant d’écrire. Si un élève ne peut pas être associé sans ambiguïté à la liste Mozaïk, la synchronisation s’arrête.
