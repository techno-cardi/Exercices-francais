Test du favori JavaScript

Ce test ne touche à aucune donnée. Il doit seulement afficher une alerte dans Mozaïk.

Option la plus fiable :
1. Copie le code ci-dessous.
2. Crée un nouveau favori Chrome.
3. Nom : Test Mozaïk.
4. Dans URL, colle le code en t’assurant qu’il commence exactement par javascript:.
javascript:alert('Favori JavaScript OK')
Ensuite : ouvre Mozaïk et clique sur le favori Test Mozaïk. Tu dois voir « Favori JavaScript OK ».
